# Текст для нового чата

Продолжаем проект avocado.rest. Репозиторий github.com/regprogavocado-art/avocadik,
локальная рабочая копия в корне проекта. Сначала прочитай
design-system/avocado/HANDOFF.md, README.md, site/README.md и
design-system/avocado/MASTER.md, затем проверь git status и текущую публикацию.

Переработка сайта под анонимный хостинг уже завершена и опубликована:
тарифы, флаги, фильтры, подбор домена, заказ через чат; Hass/Ettinger отдельным
блоком. Домен остаётся на GitHub Pages, админка и рендер D1 на Cloudflare Pages.
Не переносить DNS, не показывать поставщиков и ссылку на админку, не менять
доступы без необходимости. Секреты уже сохранены локально в gitignored файлах;
пути есть в HANDOFF.md, значения не выводить и не коммитить.

Работай автономно, пиши по-русски кратко. Учитывай последнюю задачу владельца,
а не начинай автоматически все будущие этапы из передачи. Если новой задачи
пока нет, коротко подтверди, что контекст прочитан.
