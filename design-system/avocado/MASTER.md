# Avocado — Design System (MASTER)

Источник истины для сайта avocado.rest. Сгенерировано скиллом ui-ux-pro-max
(паттерн «Real-Time / Operations Landing»), затем палитра и типографика
переопределены по утверждённому референсу (премиальный тёмный, мята + золото).
Предложенный скиллом «Cyberpunk / matrix-green #00FF41» отклонён как не
соответствующий бренду.

## Паттерн страницы
Hero (продукт + live-превью дашборда) → Продукты с метриками → Почему Avocado →
Как это работает (8 этапов) → Тарифы → CTA → Футер.
Первичный CTA: в шапке («Связаться») + после метрик + в CTA-блоке.
Все CTA ведут в чат-виджет (диалог с оператором через Telegram).

## Типографика
Все шрифты локально (assets/fonts, вариативные woff2), без запросов к Google Fonts; запасные шрифты с подогнанными метриками (Manrope Fallback / Inter Fallback) убирают скачок текста при загрузке.
- Display: **Manrope** 800/700, letter-spacing -0.02em, H1 clamp(2.25rem→3.75rem) — на экранах ниже 820px (ноутбуки) H1 ограничен 3.25rem, чтобы кнопка hero оставалась над сгибом; H2 clamp(1.75rem→2.375rem)
- Body: **Inter** 400/500/600, 16px, line-height 1.6
- Utility: **JetBrains Mono** — eyebrow-подписи uppercase 11px/0.22em, цифры в дашбордах
- Типографика текста: неразрывные пробелы перед «—» и после коротких предлогов, цены `9 990 ₽` не переносятся, «ИИ-адаптеры» с word joiner после дефиса

## Сигнатура
Светящееся обсидиановое авокадо с золотой косточкой (SVG, спрайт `#i-avocado`,
крупная версия в hero). Свечение — единственный «громкий» элемент; остальное тихое.

## Эффекты и моушен
- Glass-панели: rgba(10,14,12,.55) + border 1px rgba(255,255,255,.08) + backdrop-blur 6–12px
- Reveal при скролле: opacity/translateY(14px), 500–600ms, stagger 60ms; включается только классом `.js` на `<html>` (без JS контент виден сразу); при prefers-reduced-motion — без анимации
- Бесконечные анимации (свечение косточки, точки атак на карте) — только opacity/transform, чтобы не перерисовывать SVG каждый кадр
- Hover кнопок/карточек 180ms; фокус-кольцо 2px mint; карточки с верхним бликом inset 1px rgba(255,255,255,.05)
