# Локальная проверка админки

Полный сценарий проверяет вход, все разделы на 1440/390, WCAG AA через axe,
публикацию страниц и услуг, страны, точность счетов, фиксацию реквизитов,
ручное подтверждение/выдачу, R2, новости и ответ оператора в виджете.

Тест принимает только HTTP-адреса localhost/127.0.0.1. Секреты читает из
игнорируемых `.dev.vars` и `output/local-access.json`; в логи они не попадают.
Кошелёк теста намеренно не является действительным адресом. Блокчейны и
платёжные сервисы не вызываются. Тестовые публикации скрываются в `finally`,
кошелёк отключается; история диалога и выданный тестовый счёт остаются в локальной базе.

## Запуск

1. Из корня `worker/` запустите `npm run mock:tg` — только локальный мок Telegram,
   порт 8099. Рабочий Telegram-бот для этого сценария не нужен.
2. В `site/` подготовьте `.dev.vars` и `output/local-access.json` через локальный
   `node scripts/local-setup.mjs` (см. основной README). Затем `npm run build`.
3. Из `site/` запустите `node scripts/dev-stack.mjs`. Он поднимает сайт на 4322
   и тестовый чат на 4331, применяет миграции в отдельной базе
   `D:/AvocadoREST/output/qa-stack/state`. Реальные настройки Cloudflare не использует.
4. В другом PowerShell, из `site/`:

```powershell
$env:ADMIN_UI_BASE_URL='http://127.0.0.1:4322'
$env:ADMIN_UI_CHAT_URL='http://127.0.0.1:4331'
node tests/admin-ui.cjs
```

Скриншоты и отчёт: `site/output/playwright/admin/`. Перед отправкой сообщений
скрипт записывает пробу в явно локальный чат и проверяет её через прокси сайта.
Если это разные базы/окружения, проверка останавливается до отправки из браузера.

Сайт и чат в этом сценарии работают в одном Miniflare/workerd: одновременная
запись отдельных процессов в общий файл локальной D1 приводит к конфликтам
транзакций и bookmarks. На Cloudflare D1 общий binding обслуживает платформа.

После новой сборки перезапустите `dev-stack.mjs`, чтобы он прочитал свежие модули.
Останавливайте его через родительский Node-процесс; не завершайте `workerd` отдельно.

Быстрая проверка правил CMS и авторизации без сервера:

```powershell
node --test tests/cms.test.mjs tests/auth.test.mjs
```
