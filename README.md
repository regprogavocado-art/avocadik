# NEGRA — pre-launch лендинг

3D-лендинг закрытого форума NEGRA: ASCII-череп из глифов (Three.js), говорящий
ИИ-привратник (Web Speech API), boot-прелоадер «взлом», обратный отсчёт до
открытия, пасхалки.

## Запуск

Через `file://` НЕ работает (ES-модули). Нужен любой статический сервер:

```bash
cd negra-landing
python -m http.server 8000
# → http://localhost:8000
```

Дебаг-режим: `http://localhost:8000/?debug=1` → в консоли доступен `window.__NEGRA__`
(fps, pointCount, speechMode, forceSleep() и т.д.).

## Перед выкладкой — заполнить в `js/config.js`

- `launchDateUTC` — точная дата открытия (сейчас 2026-08-04 00:00 МСК)
- `registerUrl` — URL регистрации XenForo
- `forumUrl` — URL форума (для режима «ШЛЮЗЫ ОТКРЫТЫ»)
- `telegramUrl`, `mailUrl`

## Пасхалки

- Клавиши `6` → `7` (или 7 быстрых тапов по лого на мобиле) — мем «6 7»
- 30 сек бездействия — череп засыпает; резкое движение мыши — вздрагивает
- ASCII-арт и промо-код в DevTools-консоли
- Копирование текста дописывает хвост «— утащено с NEGRA»

## Стек

Vanilla JS (ES modules + importmap), Three.js 0.170 (vendor, локально),
GSAP 3.12 + ScrollTrigger (vendor), без сборщика. Все звуки — синтез WebAudio,
без файлов. Череп — процедурный SDF, внешних 3D-моделей нет.

## Деградации

reduced-motion → статичный постер; нет WebGL → постер; нет русского TTS-голоса
или выключен звук → «терминал-режим» (печать субтитров + клики).
